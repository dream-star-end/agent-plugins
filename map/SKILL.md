# 地图 CLI（Agent 插件）

可执行文件：本插件目录下的 `map`（SKILL.md 同级，纯 Python 3 标准库，零依赖）。
数据源：OpenStreetMap 生态（Nominatim/OSRM/Overpass，均免密钥）。完整说明见同目录 `README.md`。

## 用法

所有命令默认输出 JSON；错误时 stderr 输出 `{"error": ..., "code": ...}` 且退出码 1。

- 地名查坐标：`map geocode 上海外滩`（返回经纬度与结构化地址；重名时有多条候选）
- 坐标查地址：`map reverse 31.2353,121.4876`
- 路线：`map route "北京故宫" "首都机场"`（距离 km、时长分钟；`--mode walking|cycling` 步行/骑行，`--steps` 附分步导航）
- 周边 POI：`map poi 咖啡 "上海外滩" --radius 800 --limit 10`（按直线距离排序；类别支持餐厅/咖啡/酒店/医院/药店/加油站/充电站/停车场/银行/ATM/超市/便利店/商场/地铁站/公交站/机场/景点/公园/电影院等 30 类）

地点参数都可用中文名或 `lat,lon`。全局选项：`--table`、`--compact`、`--fields a,b`。自检 `map doctor`；清单 `map commands`。

## 注意

- 数据是 OpenStreetMap 社区数据，中国境内覆盖不如高德/百度密：小商户、营业时间等字段常缺失，POI 结果为空不等于现实中没有。
- `poi` 走公共 Overpass 集群，负载高时可能慢（10-30 秒）或偶发失败（工具内部已多镜像多轮重试）；失败时如实告诉用户，别编造店名。
- 路线时长是 OSRM 按路网速度模型的估算，不含实时路况；距离/时长用于规划参考，别当导航级承诺。
- 坐标为 WGS-84；OSM 底图在中国境内展示时不存在 GCJ-02 偏移处理问题，但与国内地图 App 的坐标直接对比会有偏移，跨源对比时要说明。
