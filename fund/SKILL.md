# 基金 CLI（Agent 插件）

可执行文件：本插件目录下的 `fund`（SKILL.md 同级，纯 Python 3 标准库，零依赖）。
数据源：天天基金/东方财富公开接口（无需密钥）。完整说明见同目录 `README.md`。

## 用法

所有命令默认输出 JSON；错误时 stderr 输出 `{"error": ..., "code": ...}` 且退出码 1。

- 搜基金：`fund search 白酒`（名称/拼音/代码，全量约 2.8 万只索引本地缓存 7 天）
- 历史净值：`fund nav 161725 --limit 20`（日终官方净值、累计净值、涨跌幅、申赎状态）
- 基金资料：`fund info 161725`（费率、最低申购、近1月/3月/6月/1年收益、资产配置、前十大持仓代码、最新净值）
- 持仓明细：`fund holdings 161725`（最新季报：股票、占净值比例、持股数、市值；注意是季度披露，有滞后）
- 收益排行：`fund rank --type all|gp|hh|zq|zs|qdii|fof --by day|week|m1|m3|m6|y1|y2|y3|ytd --limit 20`

全局选项（任意位置）：`--table`、`--compact`、`--fields a,b`。自检 `fund doctor`；清单 `fund commands`。

## 注意

- **只有日终官方净值，没有盘中估值**：老牌估值接口（fundgz）已被东方财富下线，不要编造盘中估值数字；盘中只能引用最近日终净值并注明日期。
- 持仓是季报数据（滞后 1-3 个月），引用时带上 `quarter`/`as_of`。
- 排行中个别基金会出现极端涨幅（如大额赎回后的净值异动），引用榜单时对异常值保持警惕。
