# 热搜聚合 CLI（Agent 插件）

可执行文件：本插件目录下的 `hot`（SKILL.md 同级，纯 Python 3 标准库，零依赖）。
数据源为各平台公开接口（无需密钥）。完整说明见同目录 `README.md`。

## 用法

所有命令默认输出 JSON；错误时 stderr 输出 `{"error": ..., "code": ...}` 且退出码 1。

- 全部源聚合：`hot list [--limit 30]`（五源各返回 ok/失败状态，单源失败不影响其他源）
- 单个源：`hot list --source zhihu|baidu|toutiao|bili|weibo`
  - zhihu 知乎热榜（标题 + 热度文本）
  - baidu 百度热搜（标题，热度指数该接口不提供）
  - toutiao 头条热榜（标题 + 热度值）
  - bili B站热门视频（标题、UP主、播放量）
  - weibo 微博热搜（标题 + 搜索热度 + 热/沸/新标签；走访客 cookie 流程，最不稳定，失败时在聚合结果里单独标 error）

全局选项（任意位置）：`--table`、`--compact`、`--fields a,b`。自检 `hot doctor`（逐源）；清单 `hot commands`。

## 注意

- **各源热度口径不同、不可跨源比较**：知乎是「万热度」文本、微博是搜索量、头条是热度值、百度不提供数值、B站是播放量。做选题/汇报时按源分别呈现，别混排成一个总榜宣称是全网排名。
- 热榜变化快，引用时注明抓取时间（当前时间即可）。
- 微博源依赖访客流程（cookie 缓存在 ~/.hot_cache/），偶发失败属正常，聚合模式下会自动隔离。
